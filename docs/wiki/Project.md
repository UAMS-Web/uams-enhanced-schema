Where the plugin is developed and how to report a problem.

- [Repository](https://github.com/UAMS-Web/uams-enhanced-schema): the code, the tests and these pages, in `docs/wiki/`.
- [Report a problem](https://github.com/UAMS-Web/uams-enhanced-schema/issues): open an issue with the page type, what the page source shows and what you expected.
- [Releases](https://github.com/UAMS-Web/uams-enhanced-schema/releases): what changed in each version.
- [Contributing](https://github.com/UAMS-Web/uams-enhanced-schema/blob/main/CONTRIBUTING.md): how a change reaches `main`.

The plugin was written as a stopgap: when the site moves to Statamic, its templates will write this schema themselves.
